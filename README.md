# OpenCart Manual Testing Project

## Project Overview

This project demonstrates manual testing of the OpenCart registration module.

The objective was to validate user registration functionality, input validations, and error handling.

## Application Tested

OpenCart Demo Website
https://demo.opencart.com/

## Testing Type

* Functional Testing
* Negative Testing
* Boundary Value Testing
* Validation Testing

## Test Artifacts

* Test Scenarios
* Test Cases (22 cases)
* Bug Reports
* Screenshots

## Tools Used

* Excel (Test Case Documentation)
* Manual Testing Techniques

## Key Findings

Several validation issues were identified, including:

* Weak passwords accepted
* Numeric values allowed in names
* Special characters accepted in name fields
* Password length validation issues
